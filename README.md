To launch this game, download the LOVE 2D Framework at: https://love2d.org/ 

Simply Drag and drop the Gameboy folder on the love 2d EXE (should be on your desktop after installation, if not find the location of the download folder and find love.exe)

Controls: Arrow Keys to move around, press P to pause during gameplay.

Objective: Survive as long as you can and collect the vegtables/fruit to increase your score!
